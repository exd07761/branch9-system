v1.1 Migration — Pilot Tool

IM-7A (IM7_PLANNING.md) — creates real Case documents and links existing Hearing case rows to them. Not part of the Clerk-facing application, not linked from anywhere in it, and requires Administrator sign-in. Unlike migration-dryrun.html, this tool DOES write to Firestore — read every notice below before using it.

This tool performs real writes once you explicitly confirm a run. Opening this page does nothing by itself — no analysis and no migration happen automatically. Take a fresh backup (backup.html) before running anything here. No rollback tooling exists yet (that's a separate, later milestone) — the only way back right now is that backup.

Before you start

  • Take a fresh backup via backup.html first. This tool cannot verify that you did — it will ask you to confirm it before the first write, and that confirmation is the only check that exists.
  • This creates cases documents and sets caseId on existing hearingCases rows. It never modifies or deletes any hearings or existing hearingCases field other than adding that one reference.
  • Safe to re-run: anything already migrated in a prior run is detected and skipped automatically, rather than duplicated.
  • Use the pilot limit below to migrate a small number of cases first, review the results, then run again for the rest.
